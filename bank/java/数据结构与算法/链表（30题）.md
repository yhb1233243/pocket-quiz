# 1. 实现单链表的基本操作（插入、删除、查找、打印）。

好的，下面是一个用Java语言实现单链表基本操作（插入、删除、查找、打印）的示例代码：

```Java
class Node {
    int data;
    Node next;

    public Node(int data) {
        this.data = data;
        this.next = null;
    }
}

class SinglyLinkedList {
    private Node head;

    // 插入节点到链表末尾
    public void insert(int data) {
        Node newNode = new Node(data);
        if (head == null) {
            head = newNode;
        } else {
            Node current = head;
            while (current.next != null) {
                current = current.next;
            }
            current.next = newNode;
        }
    }

    // 删除指定值的节点
    public void delete(int data) {
        if (head == null) return;

        if (head.data == data) {
            head = head.next;
            return;
        }

        Node current = head;
        while (current.next != null && current.next.data != data) {
            current = current.next;
        }

        if (current.next != null) {
            current.next = current.next.next;
        }
    }

    // 查找指定值的节点
    public boolean search(int data) {
        Node current = head;
        while (current != null) {
            if (current.data == data) {
                return true;
            }
            current = current.next;
        }
        return false;
    }

    // 打印链表中的所有节点
    public void printList() {
        Node current = head;
        while (current != null) {
            System.out.print(current.data + " -> ");
            current = current.next;
        }
        System.out.println("null");
    }

    public static void main(String[] args) {
        SinglyLinkedList list = new SinglyLinkedList();
        list.insert(1);
        list.insert(2);
        list.insert(3);
        list.printList(); // 输出: 1 -> 2 -> 3 -> null

        list.delete(2);
        list.printList(); // 输出: 1 -> 3 -> null

        System.out.println(list.search(3)); // 输出: true
        System.out.println(list.search(4)); // 输出: false
    }
}
```

1. **Node类**：表示链表中的一个节点，包含数据和指向下一个节点的引用。
2. **SinglyLinkedList类**：实现了单链表的基本操作。
  - `insert(int data)`：在链表末尾插入一个新节点。
  - `delete(int data)`：删除链表中第一个值为`data`的节点。
  - `search(int data)`：查找链表中是否存在值为`data`的节点。
  - `printList()`：打印链表中的所有节点。
3. **main方法**：测试上述功能。

你可以根据需要扩展这些基本操作，例如在特定位置插入或删除节点等。

# 2. 实现双向链表的基本操作（插入、删除、查找、打印）。

```Java
class DoublyNode {
    int data;
    DoublyNode next;
    DoublyNode prev;

    public DoublyNode(int data) {
        this.data = data;
        this.next = null;
        this.prev = null;
    }
}

class DoublyLinkedList {
    private DoublyNode head;

    // 在链表末尾插入节点
    public void insert(int data) {
        DoublyNode newNode = new DoublyNode(data);
        if (head == null) {
            head = newNode;
        } else {
            DoublyNode current = head;
            while (current.next != null) {
                current = current.next;
            }
            current.next = newNode;
            newNode.prev = current;
        }
    }

    // 删除指定值的节点
    public void delete(int data) {
        if (head == null) return;

        DoublyNode current = head;
        while (current != null && current.data != data) {
            current = current.next;
        }

        if (current == null) return; // 没有找到要删除的节点

        if (current.prev != null) {
            current.prev.next = current.next;
        } else {
            head = current.next; // 如果要删除的是头节点
        }

        if (current.next != null) {
            current.next.prev = current.prev;
        }
    }

    // 查找指定值的节点
    public boolean search(int data) {
        DoublyNode current = head;
        while (current != null) {
            if (current.data == data) {
                return true;
            }
            current = current.next;
        }
        return false;
    }

    // 打印链表中的所有节点
    public void printList() {
        DoublyNode current = head;
        while (current != null) {
            System.out.print(current.data + " <-> ");
            current = current.next;
        }
        System.out.println("null");
    }

    public static void main(String[] args) {
        DoublyLinkedList list = new DoublyLinkedList();
        list.insert(1);
        list.insert(2);
        list.insert(3);
        list.printList(); // 输出: 1 <-> 2 <-> 3 <-> null

        list.delete(2);
        list.printList(); // 输出: 1 <-> 3 <-> null

        System.out.println(list.search(3)); // 输出: true
        System.out.println(list.search(4)); // 输出: false
    }
}
```

2. **DoublyLinkedList类**：实现了双向链表的基本操作。

# 3. 反转单链表。

反转单链表是一个常见的操作，可以通过迭代或递归的方法来实现。下面分别给出这两种方法的实现：

### 3.1. 方法一：迭代法

```Java
class Node {
    int data;
    Node next;

    public Node(int data) {
        this.data = data;
        this.next = null;
    }
}

class SinglyLinkedList {
    private Node head;

    // 插入节点到链表末尾
    public void insert(int data) {
        Node newNode = new Node(data);
        if (head == null) {
            head = newNode;
        } else {
            Node current = head;
            while (current.next != null) {
                current = current.next;
            }
            current.next = newNode;
        }
    }

    // 打印链表中的所有节点
    public void printList() {
        Node current = head;
        while (current != null) {
            System.out.print(current.data + " -> ");
            current = current.next;
        }
        System.out.println("null");
    }

    // 反转链表
    public void reverse() {
        Node prev = null;
        Node current = head;
        Node next = null;
        while (current != null) {
            next = current.next; // 保存下一个节点
            current.next = prev; // 当前节点指向前一个节点
            prev = current;      // 前一个节点移动到当前节点
            current = next;      // 当前节点移动到下一个节点
        }
        head = prev; // 更新头节点为最后一个节点
    }

    public static void main(String[] args) {
        SinglyLinkedList list = new SinglyLinkedList();
        list.insert(1);
        list.insert(2);
        list.insert(3);
        list.printList(); // 输出: 1 -> 2 -> 3 -> null

        list.reverse();
        list.printList(); // 输出: 3 -> 2 -> 1 -> null
    }
}
```

# 4. 反转双向链表。

# 5. 判断一个链表是否为回文链表。

要判断一个链表是否为回文链表，可以使用以下步骤：

1. 使用快慢指针找到链表的中间节点。
2. 反转链表的后半部分。
3. 比较前半部分和反转后的后半部分是否相同。
4. 恢复链表（可选）。
5. 返回结果。

下面是一个完整的Java实现：

```Java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class PalindromeLinkedList {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        // Step 1: Find the middle of the linked list using slow and fast pointers
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // Step 2: Reverse the second half of the linked list
        ListNode reversedSecondHalf = reverseList(slow);

        // Step 3: Compare the first half and the reversed second half
        ListNode firstHalf = head;
        while (reversedSecondHalf != null) {
            if (firstHalf.val != reversedSecondHalf.val) return false;
            firstHalf = firstHalf.next;
            reversedSecondHalf = reversedSecondHalf.next;
        }

        return true;
    }

    private ListNode reverseList(ListNode head) {
        ListNode prev = null;
        while (head != null) {
            ListNode next = head.next;
            head.next = prev;
            prev = head;
            head = next;
        }
        return prev;
    }

    public static void main(String[] args) {
        PalindromeLinkedList solution = new PalindromeLinkedList();

        // Example usage:
        ListNode head = new ListNode(1);
        head.next = new ListNode(2);
        head.next.next = new ListNode(2);
        head.next.next.next = new ListNode(1);

        System.out.println(solution.isPalindrome(head)); // Output: true
    }
}
```

### 5.1. 解释：

1. **找到中间节点**：使用快慢指针法，`slow`每次走一步，`fast`每次走两步。当`fast`到达链表末尾时，`slow`正好在链表的中间位置。
2. **反转后半部分链表**：从中间节点开始反转链表的后半部分。
3. **比较两部分**：同时遍历原链表的前半部分和反转后的后半部分，逐个节点进行比较。如果所有对应节点的值都相等，则链表是回文的。
4. **恢复链表（可选）**：如果需要保持链表的原始结构，可以在比较完成后再次反转后半部分链表。

这个算法的时间复杂度是O(n)，空间复杂度是O(1)。

# 6. 合并两个有序链表。

合并两个有序链表是一个常见的面试题。假设我们有两个升序排列的链表，我们需要将它们合并成一个新的升序链表。

下面是一个完整的Java实现：

```Java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class MergeTwoSortedLists {
    public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        // 创建一个虚拟头节点，方便处理边界情况
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        // 遍历两个链表，直到其中一个为空
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                current.next = l1;
                l1 = l1.next;
            } else {
                current.next = l2;
                l2 = l2.next;
            }
            current = current.next;
        }

        // 如果有一个链表还有剩余节点，直接连接到结果链表的末尾
        if (l1 != null) {
            current.next = l1;
        } else {
            current.next = l2;
        }

        // 返回合并后的链表（跳过虚拟头节点）
        return dummy.next;
    }

    public static void main(String[] args) {
        // 创建测试用例
        ListNode l1 = new ListNode(1);
        l1.next = new ListNode(2);
        l1.next.next = new ListNode(4);

        ListNode l2 = new ListNode(1);
        l2.next = new ListNode(3);
        l2.next.next = new ListNode(4);

        MergeTwoSortedLists solution = new MergeTwoSortedLists();
        ListNode mergedList = solution.mergeTwoLists(l1, l2);

        // 打印合并后的链表
        while (mergedList != null) {
            System.out.print(mergedList.val + " ");
            mergedList = mergedList.next;
        }
    }
}
```

### 6.1. 解释：

1. **定义链表节点类**：`ListNode`类表示链表的节点，每个节点包含一个整数值和一个指向下一个节点的引用。
2. **合并函数**：`mergeTwoLists`方法接受两个有序链表的头节点作为参数，并返回合并后的新链表的头节点。
  - 使用一个虚拟头节点`dummy`来简化操作，避免处理头节点为空的情况。
  - 使用一个指针`current`来跟踪新链表的最后一个节点。
  - 遍历两个链表，比较当前节点的值，将较小的节点连接到新链表中，并移动相应的指针。
  - 当其中一个链表遍历完后，将另一个链表的剩余部分直接连接到新链表的末尾。
3. **主函数**：在`main`方法中创建两个测试链表，调用`mergeTwoLists`方法进行合并，并打印合并后的链表。

这个算法的时间复杂度是O(n + m)，其中n和m分别是两个链表的长度。空间复杂度是O(1)，因为我们只使用了常数级别的额外空间。

# 7. 在单链表中找到中间节点。

在单链表中找到中间节点是一个常见的问题，可以使用快慢指针法（也称为龟兔赛跑算法）来高效地解决这个问题。

### 7.1. 快慢指针法

1. **初始化两个指针**：一个慢指针`slow`和一个快指针`fast`，都指向链表的头节点。
2. **遍历链表**：快指针每次移动两步，慢指针每次移动一步。当快指针到达链表末尾时，慢指针正好位于链表的中间节点。

下面是一个完整的Java实现：

```Java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class FindMiddleNode {
    public ListNode findMiddleNode(ListNode head) {
        if (head == null) return null;

        ListNode slow = head;
        ListNode fast = head;

        // 快慢指针遍历链表
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 当快指针到达末尾时，慢指针即为中间节点
        return slow;
    }

    public static void main(String[] args) {
        // 创建测试用例
        ListNode head = new ListNode(1);
        head.next = new ListNode(2);
        head.next.next = new ListNode(3);
        head.next.next.next = new ListNode(4);
        head.next.next.next.next = new ListNode(5);

        FindMiddleNode solution = new FindMiddleNode();
        ListNode middleNode = solution.findMiddleNode(head);
```

# 8. 删除单链表中的重复元素。

删除单链表中的重复元素是一个常见的问题。我们可以使用一个哈希集合（`HashSet`）来跟踪已经遇到的元素，从而在遍历链表时删除重复的元素。

下面是一个完整的Java实现：

```Java
import java.util.HashSet;

class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class RemoveDuplicatesFromLinkedList {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) return null;

        HashSet<Integer> seen = new HashSet<>();
        ListNode current = head;
        seen.add(current.val);

        while (current.next != null) {
            if (seen.contains(current.next.val)) {
                // 跳过重复节点
                current.next = current.next.next;
            } else {
                // 记录新值并移动到下一个节点
                seen.add(current.next.val);
                current = current.next;
            }
        }

        return head;
    }

    public static void main(String[] args) {
        // 创建测试用例
        ListNode head = new ListNode(1);
        head.next = new ListNode(2);
        head.next.next = new ListNode(3);
        head.next.next.next = new ListNode(2);
        head.next.next.next.next = new ListNode(4);

        RemoveDuplicatesFromLinkedList solution = new RemoveDuplicatesFromLinkedList();
        ListNode result = solution.deleteDuplicates(head);

        // 打印结果链表
        while (result != null) {
            System.out.print(result.val + " ");
            result = result.next;
        }
    }
}
```

### 8.1. 解释：

1. **定义链表节点类**：`ListNode`类表示链表的节点，每个节点包含一个整数值和一个指向下一个节点的引用。
2. **删除重复元素的方法**：`deleteDuplicates`方法接受链表的头节点作为参数，并返回处理后的链表头节点。
  - 如果链表为空，直接返回`null`。
  - 使用一个哈希集合`seen`来记录已经遇到的元素。
  - 初始化当前节点`current`为头节点，并将头节点的值添加到`seen`中。
  - 遍历链表，检查当前节点的下一个节点的值是否已经在`seen`中：
    - 如果在`seen`中，说明是重复元素，跳过该节点（即设置`current.next = current.next.next`）。
    - 如果不在`seen`中，将该值添加到`seen`中，并移动到下一个节点。
3. **主函数**：在`main`方法中创建一个测试链表，调用`deleteDuplicates`方法删除重复元素，并打印处理后的链表。

这个算法的时间复杂度是O(n)，其中n是链表的长度。空间复杂度是O(n)，因为我们需要额外的哈希集合来存储已遇到的元素。

# 9. 检测单链表中是否存在环。

检测单链表中是否存在环是一个经典的问题，可以使用快慢指针法（也称为龟兔赛跑算法）来高效地解决这个问题。

### 9.1. 快慢指针法

1. **初始化两个指针**：一个慢指针`slow`和一个快指针`fast`，都指向链表的头节点。
2. **遍历链表**：快指针每次移动两步，慢指针每次移动一步。如果链表中存在环，快指针最终会追上慢指针；如果不存在环，快指针会到达链表末尾（即`null`）。

下面是一个完整的Java实现：

```Java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class LinkedListCycleDetection {
    public boolean hasCycle(ListNode head) {
        if (head == null || head.next == null) return false;

        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

            if (slow == fast) {
                return true; // 存在环
            }
        }

        return false; // 不存在环
    }

    public static void main(String[] args) {
        // 创建测试用例
        ListNode head = new ListNode(3);
        ListNode node1 = new ListNode(2);
        ListNode node2 = new ListNode(0);
        ListNode node3 = new ListNode(-4);

        head.next = node1;
        node1.next = node2;
        node2.next = node3;
        node3.next = node1; // 创建一个环

        LinkedListCycleDetection solution = new LinkedListCycleDetection();
        boolean result = solution.hasCycle(head);

        // 打印结果
        System.out.println("Does the linked list have a cycle? " + result); // Output: true
    }
}
```

### 9.2. 解释：

1. **定义链表节点类**：`ListNode`类表示链表的节点，每个节点包含一个整数值和一个指向下一个节点的引用。
2. **检测环的方法**：`hasCycle`方法接受链表的头节点作为参数，并返回一个布尔值，表示链表中是否存在环。
  - 如果链表为空或只有一个节点，直接返回`false`。
  - 使用两个指针`slow`和`fast`，初始时都指向头节点。
  - 遍历链表，快指针每次移动两步，慢指针每次移动一步。如果快指针和慢指针相遇，说明存在环，返回`true`。如果快指针到达链表末尾（即`null`），说明不存在环，返回`false`。

# 10. 找到单链表中的环的入口点。

找到单链表中环的入口点是一个经典的问题，通常与检测环的存在一起解决。我们可以使用快慢指针法来检测环的存在，然后通过数学推导找到环的入口点。

### 10.1. 步骤：

1. **检测环的存在**：使用快慢指针法。如果存在环，快指针最终会追上慢指针。
2. **找到环的入口点**：
  - 当快慢指针相遇时，假设环的长度为`L`，从头节点到环入口的距离为`a`，从相遇点到环入口的距离为`b`。
  - 设从头节点出发的指针和从相遇点出发的指针都以相同速度前进，它们会在环入口点相遇。
  - 具体地，从头节点出发的指针走`a + b`步，从相遇点出发的指针也走`a + b`步，两者在环入口点相遇。

下面是一个完整的Java实现：

```Java

    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

    public ListNode detectCycle(ListNode head) {
        if (head == null || head.next == null) return null;

        ListNode slow = head;
        ListNode fast = head;

        // 检测是否存在环
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

            if (slow == fast) {
                break; // 存在环，跳出循环
            }
        }

        // 如果不存在环，返回null
        if (fast == null || fast.next == null) return null;

        // 找到环的入口点
        slow = head;
        while (slow != fast) {
            slow = slow.next;
            fast = fast.next;
        }

        return slow; // 环的入口点
    }

    public static void main(String[] args) {
        // 创建测试用例
        ListNode head = new ListNode(3);
        ListNode node1 = new ListNode(2);
        ListNode node2 = new ListNode(0);
        ListNode node3 = new ListNode(-4);

        head.next = node1;
        node1.next = node2;
        node2.next = node3;
        node3.next = node1; // 创建一个环

        LinkedListCycleEntryPoint solution = new LinkedListCycleEntryPoint();
        ListNode entry = solution.detectCycle(head);

        // 打印结果
        System.out.println("The entry point of the cycle is at node with value: " + entry.val); // Output: 2
    }
}
```

# 11. 删除单链表中的环。

删除单链表中的环可以通过找到环的入口点，然后将其断开来实现。以下是一个完整的Java实现：

# 14. 实现一个函数来检测两个单链表是否相交，并找出交点。

要检测两个单链表是否相交，并找出交点，我们可以使用以下步骤：

1. 计算两个链表的长度。
2. 将较长的链表的头指针向前移动，直到它与较短的链表长度相同。
3. 同时遍历两个链表，直到找到相同的节点或到达链表末尾。

以下是Java代码实现：

```Java

    int val;
    ListNode next;
    ListNode(int x) {
        val = x;
        next = null;
    }
}

public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return null;

        // 获取两个链表的长度
        int lenA = getLength(headA);
        int lenB = getLength(headB);

        // 将较长的链表的头指针向前移动，直到它与较短的链表长度相同
        while (lenA > lenB) {
            headA = headA.next;
            lenA--;
        }
        while (lenB > lenA) {
            headB = headB.next;
            lenB--;
        }

        // 同时遍历两个链表，直到找到相同的节点或到达链表末尾
        while (headA != null && headB != null) {
            if (headA == headB) {
                return headA;
            }
            headA = headA.next;
            headB = headB.next;
        }

        return null; // 没有交点
    }

    private int getLength(ListNode node) {
        int length = 0;
        while (node != null) {
            length++;
            node = node.next;
        }
        return length;
    }
}
```

# 20. 实现一个函数来判断一个单链表是否是回文链表。

要判断一个单链表是否是回文链表，我们可以使用快慢指针找到链表的中点，然后反转后半部分链表，最后比较前半部分和反转后的后半部分是否相同。

以下是Java代码实现：

```Java

    int val;
    ListNode next;
    ListNode(int x) {
        val = x;
        next = null;
    }
}

public class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        // 使用快慢指针找到中点
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 反转后半部分链表
        ListNode secondHalfStart = reverse(slow);
        ListNode firstHalfStart = head;

        // 比较前半部分和反转后的后半部分
        while (secondHalfStart != null) {
            if (firstHalfStart.val != secondHalfStart.val) return false;
            firstHalfStart = firstHalfStart.next;
            secondHalfStart = secondHalfStart.next;
        }

        return true;
    }

    private ListNode reverse(ListNode head) {
        ListNode prev = null;
        while (head != null) {
            ListNode next = head.next;
            head.next = prev;
            prev = head;
            head = next;
        }
        return prev;
    }
}
```

# 27. 实现一个函数来检测两个单链表是否互为旋转缩放。

以下是Java代码实现：

```Java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) {
        val = x;
        next = null;
    }

public class Solution {
    public boolean areRotatedScales(ListNode headA, ListNode headB) {
        Stack<Integer> stack = new Stack<>();

        // 将第一个链表的所有元素压入栈中
        ListNode currentA = headA;
        while (currentA != null) {
            stack.push(currentA.val);
            currentA = currentA.next;
        }

        // 遍历第二个链表，并检查每个元素是否与栈顶元素相同

        while (currentB != null) {
            if (stack.isEmpty() || stack.pop() != currentB.val) {
                return false; // 如果栈为空或栈顶元素不等于当前节点的值，返回false
            }
            currentB = currentB.next;
        }

        return stack.isEmpty(); // 如果栈为空，则两个链表互为旋转缩放，返回true；否则返回false
    }
}
```

# 29. 实现一个函数来检测两个单链表是否互为旋转缩放平移镜像。

要检测两个单链表是否互为旋转缩放平移镜像，我们需要定义一个更复杂的逻辑。首先，我们需要考虑如何表示“旋转”、“缩放”和“平移”。对于这个例子，我们可以假设：

- **旋转**：将链表中的元素循环移动。
- **缩放**：改变链表中元素的值（例如，乘以一个常数）。
- **平移**：在链表中添加或删除元素。
- **镜像**：反转链表。

为了简化问题，我们可以先实现一个函数来检测两个链表是否互为镜像，然后再考虑其他操作。以下是Java代码实现：

```Java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) {
        val = x;
        next = null;
    }
}

public class Solution {
    public boolean areMirrors(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return false;

        // Reverse the first list
        ListNode reversedA = reverseList(headA);

        // Check if reversedA is equal to headB
        return compareLists(reversedA, headB);
    }

    private ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode current = head;
        while (current != null) {
            ListNode next = current.next;
            current.next = prev;
            prev = current;
            current = next;
        }
        return prev;
    }

    private boolean compareLists(ListNode head1, ListNode head2) {
        while (head1 != null && head2 != null) {
            if (head1.val != head2.val) return false;
            head1 = head1.next;
            head2 = head2.next;
        }
        return head1 == null && head2 == null;
    }
}
```

这段代码首先定义了一个`ListNode`类来表示链表的节点。然后定义了`Solution`类，其中包含一个`areMirrors`方法来检测两个链表是否互为镜像。该方法首先检查两个链表是否为空，如果有一个为空则直接返回false。接着，它将第一个链表反转，然后比较反转后的链表和第二个链表是否相同。如果所有对应的元素都相同，并且两个链表都遍历完了，则返回true；否则返回false。
